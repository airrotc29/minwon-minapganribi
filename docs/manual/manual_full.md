OVERVIEW

이 시스템은 무엇인가요

입주사 전화, 방문, 순찰 중 발견으로 들어오는 민원을 사업소 직원 모두가 함께 올리고, 처리하고, 확인하는 앱입
니다. 단톡방처럼 편하게 쓰면서도 누가 언제 무엇을 처리했는지 기록과 통계가 자동으로 남습니다.

접수한 사람이 바로 담당을 정하거나, 발견한 사람이 직접

같은 사업소 직원은 모든 민원과 진행 상황을 함께 봅니다.

가져가 처리합니다. 보안팀이 발견해 미화팀에 넘기는 것

다른 사업소의 민원과 명단은 보이지 않습니다.

도 자연스럽게 이루어집니다.

기록이 남습니다

채팅이 함께 있습니다

"두 달 전 2층 화장실 문은 누가 언제 고쳤지?"를 바로 검

"수돗물 잠급니다, 전화 오면 작업 중이라고 안내해 주세

색할 수 있고, 같은 곳에서 반복되는 민원을 자동으로 찾아

요" 같은 소통을 앱 안에서 합니다. 민원 소식도 채팅에 자

줍니다.

동으로 올라옵니다.

준비물

스마트폰이나 PC의 인터넷 브라우저(크롬, 사파리, 삼성 인터넷)와 본사에서 받은 사업소 코드·비밀번호만 있으면 됩니
다. 앱 설치와 회원가입은 없습니다.

G E T T I N G S TA R T E D

시작하기

사업소 로그인과 이름 선택
1

관리사무소에서 안내받은 주소를 브라우저에 입력합니다. 카톡으로 받은 링크
를 눌러도 됩니다.

2

본사에서 받은 사업소 코드와 비밀번호를 입력하고 확인 을 누릅니다.

3

우리 사업소 직원 명단이 나옵니다. 본인 이름을 고르고 입장하기 를 누릅니
다. 소장은 이름 아래 소장 비밀번호를 한 번 더 넣습니다.

4

"알림 허용" 창이 뜨면 허용을 누릅니다. 내 담당 민원이 생기면 알려 줍니다.
한 번이면 충분합니다

같은 기기에서는 다음부터 자동으로 입장됩니다. 공용 PC나 다른 사람 기기라면
다 쓴 뒤 오른쪽 위 내 이름을 누르고 나가기를 누르세요.

앱으로 다운받기 (설치)

① 사업소 코드 · 비밀번호

로그인 화면의 앱으로 다운받기 를 누르면 휴대폰 홈 화면이나 PC 바탕화면에 아이
콘이 생깁니다. 기기별 방법은 다음 쪽에 있습니다.

로그인이 안 될 때
"사업소 코드 또는 비밀번호가 맞지 않습니다"가 뜨면 본사 관리자에게 코드와
비밀번호를 다시 확인하세요.
명단에 내 이름이 없으면 본사 관리자에게 명단 등록을 요청하세요.

본사 관리자

퇴사자가 생겼다는 연락을 받으면 사업소 비밀번호를 바꿉니다.
사업소 상황이 궁금하면 목록의 사진이나 이름을 눌러 소장 화면을 그대로 봅니다. 건물명이 바뀌면 ⋯ → 이름 바꾸기
로 이름만 고칩니다.
매달 초 본사 화면의 원 그래프와 맨 위(빨간) 사업소부터 보고, 필요하면 ⋯ → 월간보고서 보기로 내용을 확인합니다.

사무실 · 경리 · 서무 · 관리과장
전화와 방문 민원을 받으면 바로 접수하고, 누가 할지 뻔하면 담당 팀까지 지정합니다. 애매하면 미지정으로 두면 가까
운 직원이 가져갑니다.
채팅의 작업 안내(수돗물 · 정전 등)를 보고 입주사 전화에 답합니다.
월말에 통계에서 관리단 월간보고서를 만들어 담당 · 소장 · 관리인 결재를 받고 관리단에 제출합니다.

시설팀 · 미화팀 · 보안팀, 현장
알림이 오면 민원 → 내 담당에서 확인하고, 바로 못 가면 진행 보고로 "○○분 후 갑니다"를 남깁니다.
순찰 중 발견한 것은 직접 접수합니다. 내 일이면 "내가 처리", 다른 팀 일이면 그 팀을 지정합니다.
단수 · 정전 · 승강기 정지는 채팅 빠른 문구로 미리 알리고, 순찰 때는 지점 QR을 찍습니다(11장).
끝나면 완료 사진과 함께 완료 처리합니다. 완료 처리 자체가 보고입니다.

소장
지시하지 않아도 됩니다. 민원 목록과 채팅만 보면 지금 누가 무엇을 하고 있는지 보입니다.
미지정이 오래 남아 있거나 긴급 건이 멈춰 있을 때만 담당을 지정합니다.
통계의 반복 민원을 보고 근본 조치(설비 교체, 업체 점검)를 판단하고, 월간보고서의 개선 건의에 적습니다.
입사 · 퇴사가 생기면 상단 직원 등록·해제로 명단을 직접 고칩니다. 민원 삭제와 민원 화면 맨 위 건물 사진 넣기도 소
장만 할 수 있습니다.

처음 2주, 세 가지만

① 전화를 받으면 끊기 전에 접수 ② 현장에 가기 전 "진행 보고" 한 줄 ③ 끝나면 사진 한 장과 완료 처리. 이 세 가지만 지
키면 통계와 검색은 저절로 쌓입니다.
